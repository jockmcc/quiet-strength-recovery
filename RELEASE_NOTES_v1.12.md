# Quiet Strength Recovery v1.12

Maintenance release. The Android wrapper is built with newer tools (Android Gradle Plugin 9.5.0, Gradle 9.8.2). It also carries the earlier unreleased v1.11 wrapper: clearer daily entry, picking a workbook back up where you left off, and public support shown before the passcode. Existing passcodes, encrypted entries, minimum Android version (5.0) and signing identity are retained.

Published on 12 November 2026 at Chris's request without physical-device acceptance testing. Build and signing checks are recorded in release/release-checks-v1.12.json.
